<h2><a href="https://www.geeksforgeeks.org/problems/stacking-up-discs1315/1">Maximum Height Disc Stack</a></h2><h3>Difficulty Level : Difficulty: Hard</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given two arrays <strong>r[]</strong> and <strong>h[]</strong> of size <strong>n</strong>, where<strong> r[i] </strong>and <strong>h[i]</strong> represent the radius and height of the i-th circular disc, respectively. </span></p><p><span style="font-size: 14pt;">A disc can be placed above another disc only if both its radius and height are strictly smaller than those of the disc below it. </span></p><p><span style="font-size: 14pt;">Find the maximum possible height of a stack that can be formed using the given discs. Each disc can be used at most once.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> r[] = [5, 7, 3], h[] = [6, 5, 4]
<strong>Output:</strong> 10
<strong>Explanation:</strong> The discs (3, 4) and (5, 6) form a valid stack. Therefore, the maximum possible height is 4 + 6 = 10.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> r[] = [3, 7], h[] = [7, 4]
<strong>Output:</strong> 7
<strong>Explanation: </strong>Neither disc can be placed above the other because both required dimensions are not strictly smaller. Therefore, the maximum possible height is 7.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Dynamic Programming</code>&nbsp;<code>Sorting</code>&nbsp;
